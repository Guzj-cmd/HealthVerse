## 为什么不重新分发演示视频

验收使用的 Charades 源视频受 AI2 非商业使用许可约束，提交包和公开 GitHub 不向第三方重新分发源视频。截图用于证明项目运行界面，但不替代数据许可。

## 自行复现视频演示

1. 启动网页并进入“实时空间感知”。
2. 点击“启用摄像头”，或点击“导入视频”选择你有权使用的本地 MP4/WebM。
3. 等待 MediaPipe 显示 33 个关键点，姿态模型输出类别与置信度。
4. 若 EfficientDet 观察到工作区物体，页面会建立二维关系；未检测到时保持“等待关系证据”。
5. 姿态持续达到门槛后，Agent 才进入求证/建议状态。
6. 点击“停止输入”释放摄像头或本地视频。

原始画面不上传到 HealthVerse 后端，也不持久化到个人记忆。
