二、课程章节对应
第2章 人机交互相关学科
  - 人因、认知与任务情境共同约束健康反馈；不把单帧姿态直接解释为健康诊断。
第3章 人机交互界面
  - 七页一致导航、直接操纵、状态反馈、前馈、错误纠正、撤销与隐私控制。
第4章 概念化交互
  - Observe → Infer → Confirm 概念模型；系统区分观察、推断和用户确认。
第5章 社会化交互
  - Agent 公开证据和不确定性，允许用户纠正、拒绝或要求不再提醒。
第6章 情感化交互
  - 低打扰、渐进提醒、自主权优先；视觉保持手绘论文图语法与温和配色。
第7章 发现需求
  - 从真实学习/办公场景提炼摄像头、任务限制、空间调整、短时验证与隐私需求。
第8章 交互设计过程
  - 静态原型 → 真实模型 → 摄像头/视频 → 时序与关系 → 个人实验 → 联邦状态；保留前后截图和失败记录。
第9章 交互设计模型与理论
  - BDI 意图模型、可见性、反馈、约束、映射、用户控制和可撤销设计。
第10章 交互式系统的设计
  - 浏览器视觉推理、Servlet Agent、个人本地存储、联邦协调器、测试门槛与部署边界。

三、真实性声明
- 网页没有把未输入前的固定数字当作模型结果。
- 训练/测试按参与者隔离；未达门槛的 Charades、Edinburgh 与差分隐私分支保留 REJECTED 状态，未冒充上线能力。
- 本机两客户端只有一个物理设备指纹，因此界面显示“尚未验证多设备轮次”。
- 远端 Agent 在验收时不可用，系统真实降级到经过测试的证据约束本地回退。
- 项目是课程与研究原型，不是医疗器械。
