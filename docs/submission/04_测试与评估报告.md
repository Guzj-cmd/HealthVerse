## 浏览器端到端验收

1. 导入 D 盘真实 Charades MP4。
2. 页面显示 33 个 MediaPipe 关键点、训练姿态模型结果、时序状态和 Agent 证据。
3. 三次真实关键点校准后，localStorage 只含样本数、动作名和归一化肩宽/触达/躯干长度；不含视频或逐帧 landmarks。
4. 无视觉输入时完成两阶段短时实验：记录 `evidenceStatus=insufficient`，`memories=[]`，证明证据不足不会进入偏好记忆。
5. Agent 远端网关不可用时返回 `source=local-rule:remote_unavailable`；回复只引用给定屏幕二维证据，不臆测水杯、厘米距离、深度或长期健康结果。
6. 联邦协调器显示第 2 轮、2 个已注册客户端、1 个设备指纹、1 个已完成轮次；界面保持“尚未验证多设备轮次”。

## 未通过与外部条件

- 真实多设备联邦生产验证仍需至少两台独立物理设备连接同一 TLS 协调器。
- 摄像头到姿态关键点检测器的覆盖率需要新的、经同意采集的端到端视频 benchmark。
- 远端 Agent 提供商在本次验收时不可达；本地证据约束回退可用并有回归测试。
- 所有模型均为课程与研究原型，不是医疗器械或长期健康效果证据。
