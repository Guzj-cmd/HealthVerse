# HealthVerse 改进前后对照

## 修改前

- 手绘论文图式页面已经完成，但主要画面为静态插图。
- 姿态、分析时长、个人记忆和 Agent 结论含固定演示内容。
- 没有真实摄像头/视频输入，也没有可核验的浏览器模型推理。
- “空间调整”和“实验”没有独立阶段证据门槛。
- 联邦隐私只有说明，没有显示真实协调器状态。

对应截图：`改进前后截图/01_修改前_静态原型.jpg`

## 修改后

- 支持 `getUserMedia` 摄像头、本地视频导入、停止并释放媒体资源。
- MediaPipe Pose 在浏览器本地生成 33 点，真实训练姿态模型输出类别与置信度。
- EfficientDet-Lite0 目标检测与二维几何推理建立人体-物体关系；未知对象不进入建议。
- 时序按视频帧时间累计，持续 5 秒后才进入低打扰提醒。
- Agent 只使用当前结构化证据；远端不可用时真实降级到已测试本地回退。
- 个人身体模型由三次真实关键点校准生成，仅保存归一化派生量。
- 自我实验分为 3 分钟基线和 6 分钟方案；每阶段少于 5 秒有效证据时不写入偏好记忆。
- 联邦状态由后端查询真实协调器；同机两客户端仍显示 1 个设备指纹，不冒充多设备。
- 隐私面板区分加入意愿、是否上传、是否验证多设备和原始数据边界。

## 视觉设计保留

最终版本只融合两套指定参考：方案 A 的个性化康复工作台结构（左侧导航、中央主任务、右侧建议）与方案 B 的低对比柔和感。页面以白色、浅灰和统一的雾蓝灰为主；方案、限制、状态不再用绿、黄或粉色区分，而是用不同虚实线、描边粗细、标签和轻微阴影表达层级。每个箭头与边框仍保留不完全相同的手绘线条。

## 真实性修正

最终页面不再在没有输入时显示“已识别”“已持续若干分钟”或固定健康改善。所有可见指标均来自当前浏览器运行、冻结评估文件或真实协调器状态；无法证明的内容明确显示“等待证据”“证据不足”“尚未验证”或 `REJECTED`。
