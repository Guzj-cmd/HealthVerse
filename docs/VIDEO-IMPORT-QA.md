## 发现并修复的问题

1. 首次导入依赖 Google Storage 下载模型，短视频可能在模型就绪前播放完毕。
   - 修复：Pose Landmarker 与 EfficientDet 模型改为项目内同源资源；导入后先完成模型准备，再从 0 秒播放。
2. 视频结束后页面仍显示“视频分析中”。
   - 修复：监听 `ended`，停止动画帧循环，并显示“播放与分析完成”。
3. 连续导入多个视频时，旧异步模型回调可能覆盖新会话。
   - 修复：增加递增会话令牌，过期回调不再更新当前页面。
4. 姿态模型失败会连带阻止物体推理。
   - 修复：姿态与物体推理分开执行、独立降级。
5. 下载视频的 MIME 可能为空而被拒绝。
   - 修复：除 MIME 外，同时允许常见视频扩展名。
